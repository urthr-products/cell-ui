# Support

cell-ui is free and open-source software maintained by urthr products on a best-effort basis.

## Where to ask

- Read the [documentation](./docs/en/README.md) and [日本語ドキュメント](./docs/ja/README.md).
- Use a bug report for reproducible defects.
- Use a feature request for narrowly scoped proposals.
- Do not use public issues for security vulnerabilities; follow [SECURITY.md](./SECURITY.md).

## Support boundaries

The project does not currently include:

- guaranteed response or resolution times;
- individual integration or implementation work;
- private email, chat or video-call support;
- compatibility guarantees for unreleased or pre-1.0 APIs;
- a commitment to implement feature requests.

Questions that cannot be reproduced in the provided demo or a minimal repository may be closed or redirected.

## Financial support

Financial support is optional and never changes access to features. Funding links will be shown through GitHub's Sponsor button after the sponsorship account is activated. Sponsorship does not create a support contract, service-level agreement or implementation obligation.
