# Security Policy

## Supported versions

Until cell-ui reaches 1.0, security fixes are applied to the latest release and the current `main` branch only.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting flow:

https://github.com/urthr-products/cell-ui/security/advisories/new

Include:

- affected version or commit;
- a minimal reproduction or proof of concept;
- expected and actual behavior;
- impact and realistic attack conditions;
- any suggested mitigation.

Reports are reviewed on a best-effort basis. Please allow reasonable time for investigation before public disclosure. We will acknowledge valid reports and coordinate remediation and disclosure when practical.

## Scope

Reports should concern code maintained in this repository. Vulnerabilities in browsers, Microsoft Excel, npm, GitHub or unrelated application code should be reported to the relevant project or vendor.
