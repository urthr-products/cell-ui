## [0.1.0] - 2026-10-08

### Added

- Framework-free spreadsheet UI with virtual scrolling, cell editing, selection, resizing, fill handles, and undo/redo.
- Excel-compatible clipboard interchange for values and formatting.
- Keyboard shortcuts, formatting toolbar, context menus, formula bar, status bar, and data validation.
- ES module, IIFE, and Web Component integration options.
- Plugin APIs for commands, rendering, parsing, display resolution, and per-cell metadata.
- English and Japanese documentation, browser E2E coverage, and automated CI.
- Public project governance, support and security documentation.
- GitHub issue and pull-request templates.
- npm package metadata for `@urthr-products/cell-ui`.
